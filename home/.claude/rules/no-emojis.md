# No Emojis

No emojis in code, comments, documentation, commit messages, or any project file; they render inconsistently across terminals and fonts and resist grep. Use plain-text markers instead: `[DONE]` / `[x]`, `[FAIL]` / `[ ]`, `WARNING:`, `NOTE:`, `TIP:`, `IMPORTANT:`, `-` for bullets, `->` for arrows, `---` for separators, or omit the decoration.
